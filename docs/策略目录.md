## 阅读顺序

1. 想学习 Bottom Signal 的完整搜索和推理过程：先读 `strategy_catalog/bottom_signal_formal/README_中文学习版.md`。
2. 想在 TradingView 直接看当前主买点：导入 `strategy_catalog/bottom_signal_formal/bottom_signal_pine.pine`。
3. 想只看旧严格 MB Strong 基线：打开 `strategy_catalog/bottom_signal_formal/bottom_signal_strict_formal.pine`。
4. 想看 OBS/RS 诊断来源：读 `strategy_catalog/bottom_signal_observation_addon/README.md`。
5. 想看 2022/2026 为什么漏严格 MB 信号：读 `strategy_catalog/bottom_signal_2022_2026_research/README.md`。
6. 想看历史对照策略：读 `uptrend_dip_buy_sell`、`long_term_addon_radar`、`buy_dip_indicator`。

```powershell
.venv\Scripts\python.exe investigations\bottom_signal_search.py --symbol all --refresh-observation-search
```
